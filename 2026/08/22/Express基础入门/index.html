Express基础入门

核心就两件事：路由 + 中间件。

Express 是什么

Express 是一个极简的 HTTP 服务器框架，核心能力只有两个：

  • 路由：将 HTTP 请求映射到对应的处理函数
  • 中间件：在请求与响应之间构建处理流水线

它不内置 ORM、模板引擎或 WebSocket 等功能，而是将这些交由社区插件实现。这种精简设计使 Express 成为 Node.js 生态中最灵活、最广泛使用的 Web 框架。

中间件机制

中间件是 Express 的核心概念。每个中间件是一个函数，接收 (req, res, next) 三个参数，处理完后调用 next() 把控制权交给下一个。

核心规则：调用 next() 才会继续往下走，不调用就停在这里。

应用级 vs 路由级

内置中间件

Express 自带三个核心中间件，API 项目必备：

req 对象

请求对象，包含客户端发来的所有信息：

属性 说明
req.params URL 路由参数（/users/:id 中的 :id）
req.query URL 查询参数（?key=value），全是字符串
req.body 请求体（需要 express.json() 中间件）
req.headers 请求头
req.method HTTP 方法（GET/POST/…）
req.url 完整请求 URL
req.path 不含查询参数的路径

⚠️ req.body 默认是 undefined。不注册这个中间件，POST 请求体数据全部丢失。

res 对象

响应对象，用于向客户端发送响应：

res.send 与 res.json

方法 Content-Type 用途
res.send("text") text/html 返回 HTML 或纯文本
res.json(obj) application/json 返回 JSON 对象（自动序列化）

永远用 res.json() 返回 API 数据，不要用 res.send(JSON.stringify(...))。

响应只能发送一次

常见问题

问题 原因 解决方案
req.body 为 undefined 未注册 body 解析中间件 添加 app.use(express.json())
Cannot set headers after sent 同一请求多次调用响应方法 在分支中加 return

路由匹配不到 大小写 / 末尾斜杠不一致 /users ≠ /Users ≠ /users/
