概念

Electron 分为三大块：

  1. 主进程（Main Process）：有完全访问操作系统的 Node.js 环境
  2. 渲染进程（Renderer Process）：前端页面
  3. 预加载脚本（Preload Script）：前两者沟通的桥梁

对应模块：

  • electron/main 包含了所有主进程模块的类型。
  • electron/renderer 包含了所有渲染进程模块的类型。
  • electron/common 包含了能在主进程和渲染进程内运行的模块的类型。

预加载脚本

Electron 20 开始预加载脚本默认沙盒化，不再拥有完整的Node.js环境访问权限，只能访问以下API：

可用的 API 详细信息
Electron 模块 渲染进程模块
Node.js 模块 events、timers、url
Polyfilled 的全局模块 Buffer、process、clearImmediate、setImmediate

如果需要访问 Node.js 的完整 API，需要在 webPreferences 中设置 nodeIntegration: true，但这会带来安全风险。

沙盒化

底层本质是复用 Chromium 的沙盒化机制，用系统底层权限隔离渲染进程（过去 electron 默认将 nodejs 和 网页打通）

不开启沙盒的风险：

  • 容易受到 XSS 攻击（加载远程网页、富文本等内容）
  • 可能被恶意代码直接访问关键模块比如node:fs、node:child_process等

沙盒化核心目的：

  • 沙盒内的渲染进程只有读写内存、运行JS、渲染页面的权限
  • 任何关系到系统的操作需要通过主进程来执行

与上下文隔离的区别

  1. 上下文隔离（contextIsolation）：JS 环境隔离，页面拿不到 preload 的变量、ipcRenderer等，属于JS语言层面隔离
  2. 沙盒化：系统底层权限隔离，直接去掉了渲染进程的 Node.js 环境，属于操作系统层面隔离

Electron 20+ 默认开启沙盒化，只有当sandbox: false、nodeIntegration: true时才会关闭沙盒化

渲染进程

渲染器进程运行在 Chromium 上，使用 Chromium 的 ESM 加载器，意味着import语句：

  • 无法访问 Node.js 模块
  • 无法从node_modules加载npm包 （在没有使用vite这种工具的前提下）

预加载脚本

如果可用（取决于sandbox、contextIsolation的配置），将使用 Node.js 的 ESM 加载器，并且要求：

  • 文件必须为.mjs，因为预加载脚本会忽略package.json中的type字段

沙盒化的预加载脚本不能使用ESM，因为沙盒化后脚本被当成普通的JavaScript脚本（推荐使用打包工具处理）

非沙盒化，如果前端页面返回完全空白（Content-Length：0），页面代码会比preload先执行导致页面拿不到挂载在preload的 api。所以页面至少要有一个<html></html>

Content-Length：0出现场景

  1. 临时跳转页面，比如win.loadURL('http://127.0.0.1:3000/empty')
  2. 自定义协议空响应
  1. 页面跳转 204 No Content

预加载脚本使用 ESM 需要开启上下文隔离（contextIsolation）

窗口管理

BrowserWindow

BrowserWindow类属于主进程模块，需要在appready之后使用

配置选项

  1. 窗口尺寸与位置
  • width / height / minWidth / minHeight / maxWidth / maxHeight
  • x、y：启动定位；center：自动居中
  • resizable：是否可缩放；movable：能否拖动标题栏
  • fullscreen：全屏、fullscreenable；simpleFullscreen（mac）
  1. 外观与标题
  • title：窗口标题；icon：窗口图标（跨平台差异）
  • frame：无边框窗口；transparent：透明窗口
  • titleBarStyle：mac 原生标题栏样式（hidden /hiddenInset）
  • show：创建时是否立刻显示；opacity：窗口透明度
  1. webPreferences
  • nodeIntegration：是否允许渲染进程使用 Node.js API
  • contextIsolation：是否启用上下文隔离（推荐 true）
  • sandbox：是否启用沙箱（推荐 true）
  • preload：预加载脚本路径
  • enableRemoteModule：是否启用 remote 模块（已经废弃）
  • webSecurity：跨域开关、allowRunningInsecureContent
  1. 系统窗口特殊属性
  • alwaysOnTop：置顶窗口
  • skipTaskbar：任务栏隐藏图标
  • kiosk：售货机 / 自助终端 kiosk 模式
  • parent、modal：父子弹窗、模态对话框

实例方法

  1. 窗口显示和隐藏
  • win.show() / win.hide()
  • win.once (‘ready-to-show’) 避免白屏闪烁
  1. 窗口大小
  • maximize() / unmaximize() / isMaximized()
  • minimize() / restore()
  • setFullScreen(bool)
  • setSize() / getSize() / setBounds()
  1. 页面加载相关
  • loadFile (本地 html) /loadURL (线上地址)

  • goBack () /goForward () 页面前进后退

网络请求

在渲染进程发送请求还是在主进程发送

渲染进程：

  • 普通业务接口、不需要访问本地资源，操作多由页面事件触发
  • 接口支持跨域或者有代理
  • 依赖页面的资源如 Cookie

主进程：

  • 存在 CORS 跨域问题，并且无代理，后端无法修改
  • 文件下载、断点续传、大文件上传
  • 需要统一配置，比如net模块发送请求会自动使用系统代理
  • 有本地的自签证书
  • 有多个 session 会话、多个 cookie

渲染进程跨域处理

渲染进程使用的是 web 的请求方式，fetch或者axios，但是会受到 跨域CORS 的影响（网页默认受同源策略影响）

关闭同源策略

可在主进程关闭，但是不推荐

可以通过在主进程配置以解决跨域的问题（推荐）
